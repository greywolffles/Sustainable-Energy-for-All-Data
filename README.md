**Introduction**

This project deals with the Sustainable Energy for All (SE4ALL) dataset, which showcases the energy usage composition of nations from 1990 to 2010 alongside economic growth.

I'll be dealing with three main questions:

1.  To what extent does expanding total electricity access accelerate a nation's shift from traditional biomass toward modern renewable energy sources?
2.  How do shifts in a nation's economic structure compare to improvements in technological efficiency when it comes to driving absolute primary energy savings?
3.  Which regions have successfully achieved absolute decoupling i.e. growing economic wealth while simultaneously decreasing total primary energy consumption?

Essentially, this project is a practice for trying out data analysis for economics topics I'm not entirely familiar with. This is also my first experience working with time-series data, so I'll be writing out my thought process for each plot and method, for both your understanding and my own. The project does not go into creating a model and only delves into statistical analysis; however, its writeup is a demonstration of communicating variables and the methodology from scratch. As this entire project leans a lot more on the exploratory aspect, expect that this report is informal, and instead is a more personal explanation for my though process during the analysis section. The entire R script is also visible for this report.
