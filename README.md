# Sustainable Energy for All - Analysis Report

This data science project is essentially a walkthrough through dealing with time-series analysis through exploratory data analysis, missing value imputation, and panel regression, all done in the R programming language. All plots, code snippets, and lines of thought are documented in the RMarkdown report. Our dataset comes from [Tidy Tuesday](https://github.com/rfordatascience/tidytuesday/blob/main/data/2026/2026-05-26/readme.md), a weekly social data project hosted here on GitHub.

Taking from the .Rmd introduction, below is the short introduction to the dataset and research questions.

This project deals with the Sustainable Energy for All (SE4ALL) dataset, which showcases the energy usage composition of nations from 1990 to 2010 alongside economic growth.

I'll be dealing with three main questions:

1.  To what extent does expanding total electricity access accelerate a nation's shift from traditional biomass toward modern renewable energy sources?
2.  How do shifts in a nation's economic structure compare to improvements in technological efficiency when it comes to driving absolute primary energy savings?
3.  Which regions have successfully achieved absolute decoupling i.e. growing economic wealth while simultaneously decreasing total primary energy consumption?

This entire project walks you through not only how I approached a data science project from the profiling to regression analysis stages, but also how I familiarized myself with new jargon and concepts. Half of this report was testing out models and visualizing data, but the other half was also reading into economics and environmental science.
